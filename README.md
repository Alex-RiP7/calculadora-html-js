# Calculadora HTML + JavaScript

Calculadora simple inspirada en el diseño de la pizarra del salón de clases.

## Características

- Entradas para **Número 1** y **Número 2**
- Campo de **Resultado** (solo lectura)
- Botones para las operaciones: **+**, **-**, **×**, **÷**
- Botón de **Limpiar**
- Validación de números y protección contra división por cero
- Diseño limpio y responsivo

## Cómo usarla

1. Abre el archivo `index.html` en tu navegador.
2. Ingresa los dos números.
3. Presiona el botón de la operación que deseas realizar.
4. El resultado aparecerá en el campo correspondiente.

## Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla)
